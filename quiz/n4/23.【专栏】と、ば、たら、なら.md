# 【专栏】と、ば、たら、なら

## 规律总结

### 1. 看接续

- と：小句简体
- ば：ば形
- たら：た形
- なら：小句简体

### 2. 看限制

- ① 最万能的是**たら**（如果，之后，结果）
- ② 唯一能接续话题、提出建议的是**なら**（只要不是接续话题就是たら）
- ③ 意义最接近的两个是**と**和**ば**，同时都有
- “如果” “一……就……”两个意思，
- 其中**と**更偏向“一……就……”，**ば**更偏向“如果”
- ④ と、ば、なら不能后续命令，意志，要求，愿望等表达。

## 真题

1、ハルビンへ（）、バスがいい。
<br>A 行ったら
B 行くなら
C 行けば
D 行くと

解析：なら用于提起话题、针对这件事提建议，句意为“要是去哈尔滨的话，公交比较好”，选B。

2、北京に（）、電話を**ください**。
<br>A 着くと
B 着けば
C 着くなら
D 着いたら

解析：たら表示“到了之后”，后项接请求ください，符合题意，选D。

3、買い物に（）先生に出会った。
<br>A 行ったら
B 行くなら
C 行けば
D 行くと

解析：たら这里表示做完前项动作之后，发生偶然结果，选A。

4、食事をしようとレストランに（）、休みで残念でした。
<br>A 行くと
B 行けば
C 行ったら
D 行くなら

解析：たら表示去到之后，发现意外情况，选C。

6、そこに（）、写真が撮りたいね。
<br>A 行くと
B 行けば
C 行くたら
D 行ったら

解析：たら后项可接愿望，と・ば后项不能接愿望，C本身变形错误，选D。
