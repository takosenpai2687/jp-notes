# JLPT 官方试题集 原始材料（raw）

两套《日本语能力测试官方试题集》的全部样题原文，从 JLPT 官网下载，未做处理。

## 来源

- 《日本语能力测试官方试题集》（2012年发行）→ `https://www.jlpt.jp/samples/sample2012/`
- 《日本语能力测试官方试题集 2》（2018年发行）→ `https://www.jlpt.jp/samples/sample2018/`
- 2012 版听力问题2（Q2）音频单独放在官网 `sample2017/` 目录，已按等级归位到「音频」文件夹

## 目录结构

最高级目录是等级 N1–N5，等级下面再分两套试题集，每套内部结构相同：

```
jlpt/
├── N1/
│   ├── 官方试题集2012/
│   │   ├── 语言知识（文字·词汇·语法）·读解/
│   │   │   ├── 文字·词汇/ N1V.pdf
│   │   │   ├── 语法/      N1G.pdf
│   │   │   └── 读解/      N1R.pdf
│   │   ├── 听解/
│   │   │   ├── N1L.pdf
│   │   │   └── 音频/ N1Q1.mp3 … N1Q5.mp3
│   │   ├── 答题卡/       N1sheet.pdf
│   │   ├── 正确答案/     N1answer.pdf
│   │   └── 听解原稿/     N1script.pdf
│   └── 官方试题集2018/  …（同上）
├── N2/  …（同 N1）
├── N3/  N4/  N5/
│   └── （N3/N4/N5 的科目分组与 N1/N2 不同，见下）
└── README.md
```

**N3、N4、N5** 每套内部是三大类：

```
N3/
└── 官方试题集2012/
    ├── 语言知识（文字·词汇）/        N3V.pdf
    ├── 语言知识（语法）·读解/
    │   ├── 语法/                     N3G.pdf
    │   └── 读解/                     N3R.pdf
    ├── 听解/                          N3L.pdf + 音频
    ├── 答题卡/ 正确答案/ 听解原稿/
```

## 考试科目结构（N1/N2 vs N3/N4/N5）

| 等级 | 科目分组 |
|---|---|
| N1、N2 | ① 语言知识（文字・词汇・语法）・读解（=V+G+R）　② 听解 |
| N3、N4、N5 | ① 语言知识（文字・词汇）（=V）　② 语言知识（语法）・读解（=G+R）　③ 听解 |

## 文件命名对照

| 代号 | 含义 | 代号 | 含义 |
|---|---|---|---|
| V | 文字・词汇 | sheet | 答题卡 |
| G | 语法 | answer | 正确答案 |
| R | 读解 | script | 听解原稿 |
| L | 听解（试卷） | Q1–Q5 | 听力各题音频 |

## 注意

- **听力题数**：N1/N2/N3 有 Q1–Q5 共 5 大题；N4/N5 只有 Q1–Q4 共 4 大题（官网无 Q5）。
- 2012 版听力的 Q2 音频在官网被单独放在 `sample2017/` 目录，已按等级归位到对应「音频」文件夹。
