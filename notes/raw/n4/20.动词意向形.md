# 动词意向形

## 意义

1. 表示提议（两个人）＝ましょう的简体
2. 表示决心（一个人）

## 变形规则

- 一类：う段 → お段 + う
- 二类：去掉る + よう
- 三类：する→しよう、来る→こよう

| 原形 | 意向形 |     | 原形     | 意向形     |
| ---- | ------ | --- | -------- | ---------- |
| 言う | 言おう |     | 見る     | 見よう     |
| 書く | 書こう |     | 食べる   | 食べよう   |
| 話す | 話そう |     | 勉強する | 勉強しよう |
| 待つ | 待とう |     | 来る     | こよう     |
| 死ぬ | 死のう |     | 起きる   | 起きよう   |
| 飛ぶ | 飛ぼう |     | 行く     | 行こう     |
| 飲む | 飲もう |     | 帰る     | 帰ろう     |
| 送る | 送ろう |     |          |            |
| 泳ぐ | 泳ごう |     |          |            |

## 相关句型①——と思う・と思っている

- **意义**：表示决心，“要”
- **接续**：意向形 + と思う
- 例句
    - 明日海に<u>行こうと思います</u>。（我打算明天去海边。）
    - ずっと日本へ<u>留学しようと思っている</u>。（我一直打算去日本留学。）（长期的）

## 相关句型②——つもり

- **意义**：打算～，＝ようと思う
- **接续**：原形 / ない形 + つもり
- 例句
    - 明日海に行く<u>つもりです</u>。＝行こうと思っている。（我打算明天去海边。）
    - 明日海に行か<u>ないつもりです</u>。（否定）（我打算明天不去海边。）
    - 明日海に行く<u>つもりはない</u>。（否定）（我不打算明天去海边。）
