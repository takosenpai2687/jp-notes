# 动词变形总结

## 一类动词活用一览表（五段动词）

|      | あ段                                         | い段         | う段   | え段                   | お段       | 音便                 |
| ---- | -------------------------------------------- | ------------ | ------ | ---------------------- | ---------- | -------------------- |
| 会   | わ                                           | い           | う     | え                     | お         | っ                   |
| 書   | か                                           | き           | く     | け                     | こ         | い                   |
| 泳   | が                                           | ぎ           | ぐ     | げ                     | ご         | いで                 |
| 貸   | さ                                           | し           | す     | せ                     | そ         | し                   |
| 待   | た                                           | ち           | つ     | て                     | と         | っ                   |
| 死   | な                                           | に           | ぬ     | ね                     | の         | んで                 |
| 遊   | ば                                           | び           | ぶ     | べ                     | ぼ         | んで                 |
| 飲   | ま                                           | み           | む     | め                     | も         | んで                 |
| 送   | ら                                           | り           | る     | れ                     | ろ         | っ                   |
| 活用 | +ない=ない形<br>+せる=使役形<br>+れる=受身形 | +ます=ます形 | 辞書形 | +ば=ば形<br>+る=可能形 | +う=意向形 | +て=て形<br>+た=た形 |

## 二类动词活用一览表

| 規則             | +      | 活用形 | 例         |
| ---------------- | ------ | ------ | ---------- |
| 去掉る（食べる） | ます   | ます形 | 食べます   |
| 去掉る（食べる） | て     | て形   | 食べて     |
| 去掉る（食べる） | た     | た形   | 食べた     |
| 去掉る（食べる） | ない   | ない形 | 食べない   |
| 去掉る（食べる） | よう   | 意向形 | 食べよう   |
| 去掉る（食べる） | ろ     | 命令形 | 食べろ     |
| 去掉る（食べる） | れば   | ば形   | 食べれば   |
| 去掉る（食べる） | られる | 可能形 | 食べられる |
| 去掉る（食べる） | られる | 受身形 | 食べられる |
| 去掉る（食べる） | させる | 使役形 | 食べさせる |

| する       | し     | て   | て形   |
| する       | し     | た   | た形   |

| する       | し     | ろ   | 命令形 |

| する       | される | 不加 | 受身形 |
