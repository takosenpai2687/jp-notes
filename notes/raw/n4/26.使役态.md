# 使役态

## 意义

- ① 强制：父は私にバイオリンを練習<u>させた</u>。（父亲让我练习小提琴。）
- ② 放任：先生は子供を<u>遊ばせた</u>。（老师让孩子们玩耍。）
- ③ 诱发：梅雨がカビを<u>生えさせた</u>。（梅雨使霉菌滋生。）

## 动词变形：（使役形）

- 一类动词：词尾う段假名 → あ段假名 + せる
- 二类动词：去掉る + させる
- 三类动词：する→させる、来る→こさせる

| 原形 | 使役态   | 原形     | 使役态     |
| ---- | -------- | -------- | ---------- |
| 言う | 言わせる | 見る     | 見させる   |
| 書く | 書かせる | 食べる   | 食べさせる |
| 話す | 話させる | 勉強する | 勉強させる |
| 待つ | 待たせる | 来る     | こさせる   |
| 死ぬ | 死なせる | 起きる   | 起きさせる |
| 飛ぶ | 飛ばせる | 行く     | 行かせる   |
| 飲む | 飲ませる | 帰る     | 帰らせる   |
| 送る | 送らせる |          |            |
| 泳ぐ | 泳がせる |          |            |

## ①自动词使役句

- 一般句：Aが する
- 使役句：Bは Aを させる

- 私が行く。（我去。）
- 部長は私を行かせる。（部长让我去。）

## ②他动词使役句

- 一般句：Aは ~を する
- 使役句：Bは Aに ~を させる

- 私はコピーをする。（我复印。）
- 社長は私にコピーをさせる。（社长让我复印。）

> ⚠️ 注意：自动词使役对象用を提示，他动词使役对象用に提示
