# そうだ

## そうだ①：传闻

- 意义：表示传闻“听说”
- 接续：简体句＋そうだ；变形：そうだ、そうで
- 例句：
  - 来月学校の近くに新しいレストランが**できる**<u>そうだ</u>。
  - お手紙によると、今年も**暑い**<u>そうだ</u>。
  - 天気予報によると、北海道のほうが**寒くなった**<u>そうだ</u>。

`表示传闻时，常跟xxによると连用，表示信息的来源`

## そうだ②：样态

- 意义：表示样态
  - ①：“看起来”
  - ②：“好像要”
- 接续：
  - 动词ます形＋そうだ
  - 形容词I**去い**＋そうだ
  - 形容动词（2）＋そうだ
  - 特殊：いい→よさそうだ
  - 特殊：ない→なさそうだ
- 活用一览表：

| そうだ | 形容詞（安い） | 形容動詞（有名） | 動詞（降る） |
| ---- | ---- | ---- | ---- |
| 肯定 | 安そうだ | 有名そうだ | 降りそうだ |
| 否定 | 安くなさそうだ<br>安そうではない | 有名ではなさそうだ<br>有名そうではない | 降りそうにない<br>降りそうもない<br>降りそうにもない |

- 例句：
  - 美味しそうな料理ですね；美味し<u>そうに</u>**食べている**。
  - この店は綺麗<u>そうで</u>、高いでしょう。
  - パソコンに修理には時間が掛かり<u>そうです</u>。
`そうに＋动词、そうな＋名词、そうで＋中顿`
  - 強い風が吹いている、木が倒れそうだ。
  - もうすぐ雨が降りそうですね。

## 如何区分：看接续法

`动词ます形：样态；动词简体形：传闻`

`形容词去い：样态；形容词简体句：传闻`

`形容动词原形：样态；形容动词简体句：传闻`

- 雨が降りそうだ【样态】
- 雨が降るそうだ【传闻】
<br><br>
- 美味しそうだ【样态】
- 美味しいそうだ【传闻】
<br><br>
- 元気そうだ片【样态】
- 元気だそうだ【传闻】

## 相关句型：そうになる

- 意义：“险些，差点”
- 接续：动词ます形+そうになる【样态用法】
- 例句
  - 電池が**切れ**そうになった。
  - びっくりして、持っていたガラスを**落とし**そうになった。
