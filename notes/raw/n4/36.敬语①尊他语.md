# 敬语①

## 敬語（けいご）

- 尊他語（そんけいご / 尊敬語）：别人的动作
- 自謙語（けんじょうご / 謙譲語）：自己的动作
- 郑重語（ていねいご / 丁寧語）：不分谁的动作，表示对听话人的礼貌

## 尊他语的表现形式

尊他语

- 尊他动词 ⚠️优先
- 尊他句型
- 尊他语词头

## 尊他语——尊他动词

| 原动词           | 尊他动词     | 原动词 | 尊他动词 |
| ---------------- | ------------ | ------ | -------- |
| 食べる・飲む     | 召し上がる   | する   | なさる   |
| 来る・行く・いる | いらっしゃる | くれる | くださる |
| 来る・行く・いる | おいでになる | ※来る  | 見える   |
| 見る             | ご覧になる   | ※知る  | ご存じだ |
| 着る             | お召しになる |        |          |
| 言う             | おっしゃる   |        |          |

## 尊他语——尊他句型

①被动表尊他

- 先生もこの店をよく利用されるんですか。(老师也经常光顾这家店吗？)
- 部長は来週中国へ行かれます。(部长下周去中国)

②お＋ます形＋になる・なさる＝する

- 部長はもう<u>お帰りになりました</u>。（部长已经回去了。）
- 旅行の日程はもう<u>お決めになりましたか</u>。（旅行的日程您已经决定好了吗？）
- 先生がみんなの前で<u>ご挨拶なさいました</u>。（老师在大家面前致了辞。）

③お＋ます形＋だ＝ている

- いらっしゃいません、何か<u>お探しですか</u>。（欢迎光临，您在找什么吗？）
- パスポートは<u>お持ちですか</u>。（您带护照了吗？）

④お＋ます形＋くださる＝てくれる

- どうぞ<u>おかけください</u>。（请坐。）
- <u>ご安心ください</u>。（请放心。）
- <u>ご協力くださる</u>ようお願いします。（恳请您予以协助。）

## 尊他语——尊他语词头

お・ご：训读、音读

- お名前、お仕事、お部屋、お気持ち
- ご住所、ご両親、ご兄弟、ご家族、ご注文

※特殊：お時間、お電話、お茶、お宅

## 真题

先生「ホアさんが日本に留学すると言ったとき、ご両親は何と（　　）。」
ホア「がんばれと応援してくれました。」
1、うかがいましたか
2、申し上げましたか
3、おっしゃいましたか
4、お聞きになりましたか

（翻译）
老师：“当ホア同学说要去日本留学的时候，您父母说了什么？”
ホア：“他们鼓励我说加油。”

✅答案：3
解析：おっしゃる是「言う」的尊他语，用于描述长辈、上级的发言，本句主语是「ご両親」，需要尊他语“说”。
