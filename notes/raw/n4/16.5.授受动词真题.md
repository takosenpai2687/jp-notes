# 授受动词真题

1. おいしいね、誰が作って（ ）たのですか。
   A あげ
   B もらっ
   C いただい
   D くださっ

✅答案：D くださっ
解析：「てくださる」是「てくれる」尊敬形，表示**（长辈/身份高的人）为我做**，句子问是谁做给我们吃的，主语是「誰」（对方），用尊敬语。

2. ちょっと寒いから、ドアを閉めて（ ）ませんか。
   A やり
   B あげ
   C さしあげ
   D くれ

✅答案：D くれ
解析：「てくれませんか」表示委婉请求对方为自己做某事，译为“能不能帮我关上门？”。

3. 風邪を引いた李さんは王さんに薬を買いに行って（ ）。
   A くれた
   B もらった
   C あげた
   D やった

✅答案：B もらった

4. これは田中君がお土産に（ ）たものです。
   A もらっ
   B あげ
   C くれ
   D やっ

✅答案：C くれ
解析：「田中君が～てくれた」表示田中给我（我方）带了礼物，主语是田中，对方为我方做某事，用てくれる。

5. 田中さんは金さんからりんごを五つ（ ）ました。
   A くれ
   B やり
   C もらい
   D あげ

✅答案：C もらい
解析：「～は～からもらう」表示从某人那里得到某物，田中从金先生那里拿到5个苹果。

### 真题

6. ちょっとすみません。この仕事を手伝って（ ）んですが。
   A くれたい
   B もらいたい
   C ください
   D もらえたい

✅答案：B もらいたい
解析：「～てもらいたい」表示“想要请别人做某事”，句子意思：不好意思，想请你帮忙做这项工作。A和D本身语法形式错误，C「てください」是直接命令，后面不能接「んですが」。

7. 先生、もしよかったら、日本のことを話して（ ）ませんか。
   A あげ
   B さしあげ
   C いただけ
   D もらえ

✅答案：C いただけ
解析：对老师（长辈）请求，请对方做某事，要用尊敬表达「ていただけませんか」，意为“能否请您讲讲日本的事情？”。

8.人に（ ）物を友達にあげた。
A もらった
B あげた
C いただいた
D くれた

✅答案：A もらった
解析：「人にもらった物」= 从别人那里得到的东西。整句：把从别人那儿得到的东西送给了朋友。

9. 私はやりたいことができなかったが、子供には好きな道を進んで（ ）と思う。
   A やりたい
   B あげたい
   C くれたい
   D もらいたい

✅答案：B あげたい
解析：「～てあげたい」表示（我）想为对方做某事。句意：我没能做自己想做的事，但我想让孩子走上他喜欢的道路（想为孩子提供这样的机会）。

10. 私はやりたいことができなかったが、子供には好きな道を進んで（ ）と思う。
    A やりたい
    B あげたい
    C くれたい
    D もらいたい

- **希望孩子自己去走喜欢的路**，所以用**もらいたい**。

11. 車掌から道を教えて（ ）ました。A くれB もらいC あげD やり

✅答案：**B もらい**

1. **てもらう**：我请别人做，来源用「から」。
   句式：A は B**から** ～てもらう → 选もらい / もらいたい
2. **てくれる**：别人主动帮我，主语用「が」。
   句式：B**が** ～てくれる → 选くれ
3. **てあげる / てやる**：我帮别人做（やる用于晚辈 / 小动物）
   句式：私は B に～てあげる → 选あげ / あげたい
