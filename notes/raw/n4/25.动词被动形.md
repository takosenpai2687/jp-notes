# 动词被动形

## 意义

被动

## 动词变形：（被动形）

- 一类：う段 → あ段 + れる
- 二类：去掉る + られる
- 三类：する→される、来る→こられる

| 原形     | 动词类别 | 被动态         | 可能态     |
| -------- | -------- | -------------- | ---------- |
| 言う     | 1類      | **言われる**   | 言える     |
| 書く     | 1類      | **書かれる**   | 書ける     |
| 話す     | 1類      | **話される**   | 話せる     |
| 待つ     | 1類      | **待たれる**   | 待てる     |
| 死ぬ     | 1類      | **死なれる**   | 死ねる     |
| 飛ぶ     | 1類      | **飛ばれる**   | 飛べる     |
| 飲む     | 1類      | **飲まれる**   | 飲める     |
| 送る     | 1類      | **送られる**   | 送れる     |
| 泳ぐ     | 1類      | **泳がれる**   | 泳げる     |
| 急ぐ     | 1類      | **急がれる**   | 急げる     |
| 見る     | 2類      | **見られる**   | 見られる   |
| 食べる   | 2類      | **食べられる** | 食べられる |
| 起きる   | 2類      | **起きられる** | 起きられる |
| 勉強する | 3類      | **勉強される** | 勉強できる |
| 来る     | 3類      | **来られる**   | 来られる   |
| 行く     | 1類      | **行かれる**   | 行ける     |
| 帰る     | 1類      | **帰られる**   | 帰れる     |

## 句型变化

- ①：二项动词被动句
- ②：三项动词被动句
- ③：所属关系被动句
- ④：非特定对象被动句
- ⑤：受害者被动句

## ①二项动词被动句

> ⚠する代表主动，される代表被动。

| 主动句           | 被动句               |
| ---------------- | -------------------- |
| Aは Bを する     | Bは Aに される       |
| 猫は 魚を 食べる | 魚は 猫に 食べられる |

## ②三项动词被动句

> ⚠する代表主动，される代表被动。

| 主动句              | 被动句                  |
| ------------------- | ----------------------- |
| Aは Bに Cを する    | Bは Aに Cを される      |
| 彼は 私に 道を 聞く | 私は 彼に 道を 聞かれる |

## ③所属关系被动句

> ⚠する代表主动，される代表被动。

| 主动句                     | 被动句                  |
| -------------------------- | ----------------------- |
| Aは BのCを する            | Bは Aに Cを される      |
| 彼は 私の年（とし）を 聞く | 私は 彼に 年を 聞かれる |

❌私の年は彼に聞かれる

## ④非特定对象被动句

> ⚠する代表主动，される代表被动。

| 主动句             | 被动句            |
| ------------------ | ----------------- |
| Aは Bを する       | Bは される        |
| 人は 鐘を 鳴らす   | 鐘が 鳴らされる   |
| 人は 展覧会を 開く | 展覧会が 開かれる |

## ⑤受害者被动句

> ⚠又叫自动词被动句

| 主动句                 | 被动句                                            |
| ---------------------- | ------------------------------------------------- |
| Aが する               | BはAに される                                     |
| 雨が降る（下雨）       | 私は雨に降られる（我被雨淋了）                    |
| 犬が死ぬ（狗狗死去）   | 私は犬に死なれる（狗狗死了，我很受打击/蒙受损失） |
| 妻が怒る（妻子生气）   | 私は妻に怒られる（我被妻子训斥）                  |
| 友達が来る（朋友过来） | 私は友達に来られる（朋友来了，打扰到我了）        |
