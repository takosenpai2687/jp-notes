# 动词可能态

## 意义

① 能力
② 可能性
＝ことができる（N5）

## 变形规律

一类: う段→え段＋る

二类: 去る＋られる

三类: する→できる、来る→こられる

| 原形 | 可能态 | 原形     | 可能态     |
| ---- | ------ | -------- | ---------- |
| 言う | 言える | 見る     | 見られる   |
| 書く | 書ける | 食べる   | 食べられる |
| 話す | 話せる | 勉強する | 勉強できる |
| 待つ | 待てる | 来る     | 来られる   |
| 死ぬ | 死ねる | 起きる   | 起きられる |
| 飛ぶ | 飛べる | 行く     | 行ける     |
| 飲む | 飲める | 帰る     | 帰れる     |
| 送る | 送れる |          |            |
| 泳ぐ | 泳げる |          |            |

## 句型变化：を→が

- 日本語を話す → 日本語が話せる
- ミルクを飲む → ミルクが飲める

## 知识补充①——ら抜き言葉

- 意义：られる的「ら」在口语中常常省略
- 例子
    - 食べられる→食べれる
    - 起きられる→起きれる

## 知识补充②——見える・見られる

- 見える：客观上能看见（与意识无关）
- 見られる：主观上能看见（有意识地去看）

辨析：パンダが見える　パンダが見られる

## 知识补充③

- 意义：表示“不可能……”的时候，主语可用（は・には）
- 例：僕（は・には）理解できない。
