# 补助动词

## 什么是补助动词？

在句子里失去其本来的意义和独立性，用来补充说明中心动词的意义或者状态。

**勉強**【中心动词】して**いる**【补助动词（躲在te后面）】

## 常见的补助动词

`补助动词一般不写汉字`

| 实义动词 | 中文释义          | 补助动词 | 中文释义           |
| -------- | ----------------- | -------- | ------------------ |
| いる     | 在、有（人/动物） | ている   | 正在… / 持续状态   |
| ある     | 在、有（物品）    | てある   | （人为）做好放置着 |
| おく     | 放置              | ておく   | 预先做好、放着不管 |
| しまう   | 收拾、完了        | てしまう | 做完 / 遗憾的结果  |
| 行く     | 去                | ていく   | …下去（由近到远）  |
| 来る     | 来                | てくる   | …过来（由远到近）  |
| みる     | 看、尝试          | てみる   | 试着做…            |
| みせる   | 给…看             | てみせる | 做给别人看、证明   |
