# N4 推量四件套总结：ようだ・みたいだ・そうだ・らしい

> 配套图表：[推量四件套记忆图](0.推量四件套记忆图.png)

## 0. 一句话总纲

**同样一句「好像」，先问信息来源，再问语气**：

- 自己**亲眼看到、心里判断** → ようだ（书面／正式）／ みたいだ（口语）
- **从别人那里听来** → そうだ（传闻）／ らしい（客观传闻）
- **眼看就要发生、外观给人的印象** → そうだ（样态，专属用法）
- **表示"有……的典型样子"** → らしい（接尾词，只有它有）

## 1. 横向对比总表

| | ようだ | みたいだ | そうだ | らしい |
| --- | --- | --- | --- | --- |
| 核心意义 | ①比喩 ②例示 ③主观推测 ④目的 ⑤内容 | ①比喩 ②例示 ③推测 | ①传闻 ②样态 | ①客观推测 ②传闻 ③接尾词"典型" |
| 信息来源 | 说话人自己的感觉／判断 | 说话人自己的感觉／判断 | 传闻来自别人；样态来自外观 | 别人的话；或对象固有的特征 |
| 主观性 | 主观 | 主观（比ようだ更随意） | 传闻＝转述，样态＝外观印象 | 客观 |
| 语体 | 书面语、正式 | 口语、日常会话 | 都可 | 都可，新闻报纸常用 |
| 名词接续 | 名词＋**の**＋ようだ | 名词＋**直接**＋みたいだ | 名词＋**だ**＋そうだ（传闻） | 名词＋**直接**＋らしい |
| 连体形 | ような＋名词 | みたいな＋名词 | 样态：そうな＋名词 | らしい＋名词 |

| 独有用法 | ④目的 ⑤内容（ように＋愿望／要求） | 无 | **样态**（眼看要……） | **接尾词**（像……的样子） |

## 3. 意思重合的地方：同一句"好像"怎么区分

以"下雨"为例，四句都能译成"好像要下雨"，但依据完全不同：

- 雨が降る**ようだ**。【我看着天色／凭感觉判断 —— 主观推测】
- 雨が降る**みたいだ**。【和上一句同义，只是口语化】
- 雨が降る**そうだ**。【天气预报说的 —— 转述别人的话】
- 雨が降る**らしい**。【听人说的／消息来源可靠 —— 客观传闻】
- 雨が**降りそうだ**。【乌云压顶，眼看就要下 —— 样态外观】

**判定顺序**：情报是不是听来的？→ 是的话用 そうだ／らしい；不是的话 → 自己看到的是"外观即将发生"还是"感觉大概如此"？前者 そうだ样态，后者 ようだ／みたいだ。

## 4. 两处最容易混的"同名不同义"

### 4.1 そうだ：传闻 vs. 样态

| | 传闻 | 样态 |
| --- | --- | --- |
| 接续 | 简体句＋そうだ | ます形词干／形容词词干＋そうだ |
| 关键差别 | 前接**完整句子**（有终止形） | 前接**词干** |
| 例句 | 雨が**降る**そうだ。 | 雨が**降り**そうだ。 |
| 否定 | 降らないそうだ | 降りそうにない |
| 连体 | 不能修饰名词 | 降りそうな空、おいしそうなケーキ |
| 意思 | 听说 | 眼看要……、看起来 |
| 标志词 | ～によると | 今にも／にも |

**记法**：`降るそう＝听来的`，`降りそう＝看出来的`。动词看结尾是「る」还是「り」，形容词看有没有「い」。

### 4.2 らしい：接尾词 vs. 推量助动词

- 接尾词：名词＋らしい＝"很有……的样子、典型特征"，可以否定为**らしくない**。
  例：日本語**らしい**日本語／この絵は子供**らしくない**。
- 推量助动词：简体句＋らしい＝"好像、听说"，客观推测。
  例：美味しい**らしい**です／風邪が流行っているらしい。

**区别**：接尾词说的是"**像不像那回事**"，推量说的是"**我判断事实大概如此**"。

## 5. 常见坑

1. **名词接续别写错**：`名词＋の＋ようだ`（子供のように）／`名词＋直接＋みたいだ`（子供みたいに）／`名词＋だ＋そうだ`（元気だそうだ，不能写「元気そうだ」，那是样态！）／`名词＋直接＋らしいだ`（×）→ 名词＋らしい（○）。
2. **らしい 是イ形容词型**，没有「らしいな＋名词」这种用法：`らしい人`（○）／`らしいな人`（×）。
3. **ようだ 的"目的、内容"用法别人没有**：`わかるように説明する`（为了让人听懂）；`合格しますように`（愿望的内容，正式场合用「よう」而非「ように」的情况也存在）。
4. **传闻的 そうだ 不能修饰名词**：○ 雨が降るそうだ ／ × 雨が降るそうな日。要修饰名词必须用**样态**：降りそうな空、おいしそうなケーキ。
5. **样态 そうだ 表示"即将"时不需要亲眼所见**：`木が倒れそうだ`＝看树干倾斜做出的外观判断。
6. **ない 的样态是「なさそう」**，不是「ないそう」；**いい 是「よさそう」**，不是「いそう」。
7. **ように思う vs. と思う**：`ように思う` 更委婉、更主观，"我总觉得……"。

## 6. 一图记牢

```
     「好像」先问信息来源
 ┌────────────┴────────────┐
听来的，非亲眼所见        自己感知／判断
 ├─ そうだ（～によると）    ├─ 眼看就要发生（词干＋そう）
 └─ らしい（客观、常传消息）  │   ⇒ そうだ【样态】
                          ├─ 自己心里判断（主观、书面）
                          │   ⇒ ようだ
                          └─ 自己心里判断（口语、随意）
                              ⇒ みたいだ

 另有：名词＋らしい ＝ 典型特征（"很有……的样子"）—— 只有它有
```

**口诀**：听来 そう／らしい，看到 そう／らしい；心里想 ようだ／みたいだ；名词加らしい最典型。

## 7. 记忆锚点

| 形式 | 锚点 |
| --- | --- |
| ようだ | 名词加**の**，书面正式，比喩例示推测目的内容全能 |
| みたいだ | 和ようだ同义，**直接接名词**，口语随意 |
| そうだ | **词干＝样态（眼看要／看起来）**，**整句＝传闻（听说）** |
| らしい | 客观传闻 + **名词＋らしい＝典型特征** |
