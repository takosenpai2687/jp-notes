# ようだ

## 名词接续（连体形）

- 名词＋の＋名词
- 形容词（直接）＋名词
- 形容动词＋な＋名词
- 动词（简体）＋名词

| 接续规则                   | 最简例句           | 翻译             |
| -------------------------- | ------------------ | ---------------- |
| 名词＋の＋名词             | 中国のりんご       | 中国的苹果       |
| イ形容词＋名词             | 赤いりんご         | 红色的苹果       |
| ナ形容词＋な＋名词         | 有名なりんご       | 有名的苹果       |
| 动词（简体现在肯定）＋名词 | 落ちるりんご       | 掉落的苹果       |
| 动词（简体现在否定）＋名词 | 落ちないりんご     | 不会掉落的苹果   |
| 动词（简体过去肯定）＋名词 | 落ちたりんご       | 掉了的苹果       |
| 动词（简体过去否定）＋名词 | 落ちなかったりんご | 当时没掉落的苹果 |

## 形容动词活用（二类形容词）

| 变形规则       | 用法说明          | 例句           |
| -------------- | ----------------- | -------------- |
| だ → に ＋动词 | 作副词，修饰动词  | 静かに寝る     |
| だ → で ＋中顿 | 中顿，表并列/连接 | 静かで綺麗な人 |
| だ → な ＋名词 | 连体形，修饰名词  | 静かな人       |

## ようだ的接续

| 前项接续规则     | ようだ变形                  | 后项           | 例句                         | 翻译                 |
| ---------------- | --------------------------- | -------------- | ---------------------------- | -------------------- |
| 名词＋の         | ように                      | ＋动词         | 子供**の**よう**に**笑う     | 像孩子一样笑         |
| イ形容词（直接） | ようで                      | ＋中顿         | 嬉しい**ようで**、泣いている | 好像很开心，哭了起来 |
| 形容动词＋な     | ような                      | ＋名词         | 静か**な**よう**な**部屋     | 像是很安静的房间     |
| 动词（简体）     | ようだ/ように/ようで/ような | 动词/名词/中顿 | 雨が降る**ようだ**           | 好像要下雨           |

## ようだ 的意义

### ① 表示比喻，翻译成“好像”

- 李さんは日本語が上手で、まるで日本人の<u>ようだ</u>。
- 昨日の出会いはまるで夢の<u>ようで</u>、今でも信じられない。
- 君の心は氷の<u>ように</u>冷たい。

`※表示比喻的ようだ常常和まるで一起连用`

### ② 表示例示，翻译成“像”

- この授業の流（なが）れは次（つぎ）の<u>ようです</u>。【这节课的流程如下。】
- いつか先生の<u>ように</u>うまく日本語が話せると思う。【我想总有一天能像老师那样流利地说日语。】
- メモをしない<u>ような</u>ことをしてはいけません。【不要做不记笔记这类事情。】

### ③ 表示（主观）推测， 翻译成“好像”

- 約束の時間になっても誰も来なかった。どうも場所時間を間違えた<u>ようだ</u> 【到了约定的时间也没人来，看样子是把地点和时间搞错了。】
- 何だか風邪を引いた<u>ようで</u>、登校（とうこう）はしない。【好像感冒了，不去上学。】

`表示推测的ようだ常常和どうも、なんだか一起连用`

### ④ 表示目的；翻译成“为了”

- 子供にもわかるように、簡単な言葉で説明します。
- 皆が聞こえるように、大きな声で話してください。

### ⑤ 表示内容；相当于「と」

- 合格しますように。 【愿望的内容】
- 田中さんにお酒を飲まないように言ってください。【要求的内容】
- 世界平和が続（つづ）くようお祈り申し上げます。【祈祷的内容】

`在正式的场合中用よう，例如商务文书，正式演讲等 `

## ようだ相关句型

### ① ようにする

- 意义：表示努力做，“尽量要······”
- 接续：参考ようだ接续
- 例句：
    - 体（からだ）を丈夫（じょうぶ）にしたいので、今日から毎日運動する<u>ようにする</u>。【因为想把身体练结实，所以从今天开始坚持每天运动。】
    - 環境（かんきょう）を守るため、割（わ）り箸（ばし）を使（つか）わない<u>ようにした</u>ほうがいい。【为了保护环境，最好做到不使用一次性筷子。】

### ② ようにしている

- 意义：表示（长期）努力做；“一直尽量做到······”
- 接续：参考ようだ接续
- 例句：
    - 日本語の授業では、できるだけ日本語で話す<u>ようにしている</u>。

### ③ ようになる

- 意义：表示变化；“变得”
- 复习：名词，形容（动词)+なる;动词+ようになる
- 例句：
    - 日本へ来てから、お酒を<u>飲むようになる</u>。【来到日本之后，开始喝酒了。（习惯的变化）】
    - 日本へ来てから、お酒を<u>飲めるようになる</u>。【来到日本之后，变得能喝酒了。（能力的变化）】
    - 毎日練習しますから、やっと<u>泳げるようになった</u>。【因为每天练习，终于会游泳了。】

### ④ ようになっている

- 意义：说明事物的结构，功能；“装备有···构造是···”
- 例句：
    - 何か故障（こしょう）があった場合に、その機械は止まる<u>ようになっている</u>。【一旦出现故障，这台机器就会停止运转。】
    - 前に立つと、ドアが自動的に開く<u>ようになっている</u>。【一站到前面，门就会自动打开。】

### ⑤ ように見える

- 意义：表示看上去好像···但是实际并非如此
- 接续：参考ようだ接续
- 例句：
    - 便利なように見えたが、使てみると、それほどのものじゃない。【看上去好像很方便，但实际一用，并没有那么厉害。】
    - 夏休みの間（あいだ）に、子供たちは急に成長したように見えた。【暑假期间，孩子们看起来一下子长大了。】

### ⑥ ように思う

- 意义：认为······ように表示内容
- 区别：と思う、ように思う
- 例句：
    - 私はこの本が面白い<u>と思う</u>。【我觉得这本书很有趣。】
    - 私はこの本が面白い<u>ように思う</u>。【我感觉这本书好像挺有趣的。（更委婉，更主观）】

`ように思う更委婉，比起と思う`
