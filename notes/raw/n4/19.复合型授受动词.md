# 复合型授受动词

## 原则

- 一律从后往前看
- 第一个动词永远是实义动词

1. 幼稚園（ようちえん）で悪（わる）い事（こと）をやったら、遠慮（えんりょ）しないで叱（しか）ってやってください。

    > 解析：`～てやってください` 语法。`てやる`是给晚辈/地位低的人做某事；`てください`请你做。整句含义：**如果孩子在幼儿园做了坏事，请不要客气，尽管批评他**。注意：`てやる`不能用于长辈，这里是家长对老师说，对象是自家孩子。

2. 課長（かちょう）、最新（さいしん）の状況（じょうきょう）を李（り）さんに説明（せつめい）してあげて頂けませんか。【頂けませんか：我能不能让您做某事：课长给小李说】

3. 次（つぎ）の授業（じゅぎょう）を教（おし）えてやってもらえませんか。
   【能不能麻烦你帮我去教下一节课？】

`教えてやってもらえませんか`

1. 内层：**教えてやる**
   てやる =（B）为晚辈 C 做。B = 你，C = 学生 / 晚辈 → 你**教（晚辈）课**
2. 外层：**～てもらう**
   てもらう = 请求 B 做（B 平辈）。也就是：**我拜托你做上面这件事**
3. 合并翻译推导：
   我拜托你 → 让你去教（晚辈）下一节课
   👉 能不能麻烦你帮我去教下一节课？
   `
