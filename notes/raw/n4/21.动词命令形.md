# 动词命令形

## 意义

表示命令

## 变形规则

- 一类：う段→え段
- 二类：去る＋ろ
- 三类：する→しろ、来る→こい

| 原形 | 命令形 | 原形     | 命令形   |
| ---- | ------ | -------- | -------- |
| 言う | 言え   | 見る     | 見ろ     |
| 書く | 書け   | 食べる   | 食べろ   |
| 話す | 話せ   | 勉強する | 勉強しろ |
| 待つ | 待て   | 来る     | こい     |
| 死ぬ | 死ね   | 起きる   | 起きろ   |
| 飛ぶ | 飛べ   | 行く     | 行け     |
| 飲む | 飲め   | 帰る     | 帰れ     |
| 送る | 送れ   |          |          |
| 泳ぐ | 泳げ   |          |          |

## 相关句型①——命令形

### 使用场景

1. 较为粗鲁，多为男性使用
2. 遇到危险的时候
3. 加油打气的时候

### 例句

- 手を挙げろ！（てをあげろ）
  原形：挙げる（あげる，二类动词）｜中文：举起手来！
- お金を出せ！（おかねをだせ）
  原形：出す（だす，一类动词）｜中文：把钱拿出来！
- 行け！急げ！頑張れ！（いけ！いそげ！がんばれ！）
  原形：行く（いく）、急ぐ（いそぐ）、頑張る（がんばる），全是一类动词｜中文：去吧！快点！加油！

## 相关句型②——禁止形

### 意义

否定版命令形（不要做……、禁止……）

### 接续

动词原形 + な

### 禁止形 例句

- 動くな！（うごくな）
  原形：動く（うごく，一类动词）｜翻译：不许动！
- 触るな！（さわるな）
  原形：触る（さわる，一类动词）｜翻译：别碰！
- 撮るな！（とるな）
  原形：撮る（とる，一类动词）｜翻译：不准拍照！

## 相关句型③——なさい

### 意义

女性版命令形

### 接续

ます + なさい

### 例句

- さっさと食べなさい！
- 自分で部屋を片付けなさい！

## 相关句型④——命令形+よ

### 意义

柔和版命令形

### 接续

命令形 + よ

### 例句

- 明日、うちに来いよ！＝来て
- この写真を見ろよ！＝見て
- そう思うなよ！＝思わないで
