# 使役被动态

## 意义

被迫做某事

## 动词变形：（使役被动形）

- 一类：词尾う段→あ段＋される　特殊：話す→話させられる
- 二类：去掉る＋させられる
- 三类：する→させられる、来る→こさせられる

| 原形 | 使役被动态   | 原形     | 使役被动态     |
| ---- | ------------ | -------- | -------------- |
| 言う | 言わされる   | 見る     | 見させられる   |
| 書く | 書かされる   | 食べる   | 食べさせられる |
| 話す | 話させられる | 勉強する | 勉強させられる |
| 待つ | 待たされる   | 来る     | こさせられる   |
| 死ぬ | 死なされる   | 起きる   | 起きさせられる |
| 飛ぶ | 飛ばされる   | 行く     | 行かされる     |
| 飲む | 飲まされる   | 帰る     | 帰らされる     |
| 送る | 送らされる   |          |                |
| 泳ぐ | 泳がされる   |          |                |

# 使役被动态

- 一般句：Aが する
- 使役被动句：Aは Bに させられる

- 私が立つ。（我站着。）
- 私が先生に立たされる。（我被老师逼着站起来 / 老师让我站起来。）
