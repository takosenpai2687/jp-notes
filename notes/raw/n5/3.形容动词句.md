# 形容动词句

## 形容动词句 / II类形容词句

### 和名词的是一样的~

| 敬体表     | 肯定           | 否定                     |
| ---------- | -------------- | ------------------------ |
| 现在、将来 | ここは静かです | 静かではありません       |
| 过去       | 静かでした     | 静かではありませんでした |

| 简体表     | 肯定         | 否定             |
| ---------- | ------------ | ---------------- |
| 现在、将来 | ここは静かだ | 静かではない     |
| 过去       | 静かだった   | 静かではなかった |

## 作业：默写表格

1. この人は親切です
2. 富士山は有名です
