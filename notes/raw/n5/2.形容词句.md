# 形容词句

## 形容词分类

- 一类形容词=い形容词=形容词：以い结尾的形容词
- 二类形容词=な形容词=形容动词：不以い结尾的形容词

## I类形容词句

| 敬体表     | 肯定                             | 否定                                  |
| ---------- | -------------------------------- | ------------------------------------- |
| 现在、将来 | 今日は寒いです                   | 寒くないです（い　→ くない）          |
| 过去       | 昨日は寒かったです（い→ かった） | 寒くなかったです （い　→ くなかった） |

| 简体表     | 肯定                         | 否定                              |
| ---------- | ---------------------------- | --------------------------------- |
| 现在、将来 | 今日は寒いです               | 寒くない（い　→ くない）          |
| 过去       | 昨日は寒かった（い→ かった） | 寒くなかった （い　→ くなかった） |

## 作业：默写表格

1. りんごは赤いです
2. このケーキは美味しいです
