# 名词句

## 什么是四大句型？

四大基本句型包含：名词句，形容词句，形容动词句，动词句

## 名词句可分为

- 敬体名词句
- 简体名词句

## 什么是敬体简体？

敬体：陌生人，上级，长辈。敬体标志：です, ます

| 敬体表     | 肯定         | 否定                     |
| ---------- | ------------ | ------------------------ |
| 现在、将来 | 私は学生です | 学生ではありません       |
| 过去       | 学生でした   | 学生ではありませんでした |

| 简体表     | 肯定       | 否定             |
| ---------- | ---------- | ---------------- |
| 现在、将来 | 私は学生だ | 学生ではない     |
| 过去       | 学生だった | 学生ではなかった |

## 作业：默写表格

1. これは本です
2. 李さんは中国人です
