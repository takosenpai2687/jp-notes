# 有道发音后端接入提示词

将以下任务交给可访问有道智云官方文档的 agent：

---

请在当前仓库的 `web` 应用中实现有道智云日语语音合成后端。前端已完成，不要重写 UI，不要撤销工作区已有的单词模块改动，不要提交或推送。

## 必须保持的接口约定

当前主通道是可缓存的 `GET /api/speech?v=1&level=N5&wordId=词库原始ID&kind=reading`，例句增加 `exampleId`。`v` 为 `NEXT_PUBLIC_SPEECH_CACHE_VERSION`（默认 `1`），变更文本或音色时递增并重新部署。严格校验参数，重复参数和未知字段拒绝。成功返回 `private, max-age=31536000, immutable`，`Vary: Cookie`；错误返回 `private, no-store`。继续保留 `POST /api/speech` 兼容已有调用，请求为 JSON，严格校验 `speechRequestSchema`：

```json
{ "level": "N5", "wordId": "词库原始ID", "kind": "reading" }
```

或：

```json
{ "level": "N4", "wordId": "词库原始ID", "kind": "example", "exampleId": 123456 }
```

`exampleId` 是该单词例句的 `tatoeba_id`，不是数组下标。开放 N5–N1。不要接受任意文本、任意 URL 或调用方指定的供应商参数。

从服务端词库解析实际文本：

- `reading` 使用单词 `reading` 假名，不使用罗马音。
- `example` 验证句子属于该单词，使用原始 `ja` 字段；不要发送 `{汉字|假名}` 的 ruby 标记或英文译文。

成功返回 **音频二进制**（优先 MP3，`Content-Type: audio/mpeg`），不要返回 JSON、Base64 字符串或外部音频 URL。前端接受 MP3/WAV/OGG/MP4 音频，单条不超过 5 MiB。

失败统一返回非 2xx 状态和 `application/json`：

```json
{ "error": "面向用户的中文错误提示" }
```

建议状态：400 参数错误、401 未登录、403 非同源、404 词或例句不存在、429 限流/额度不足、502 供应商错误、503 未配置、504 超时。前端优先显示安全的 JSON 错误提示；404/501 没有 JSON 错误时才显示“尚未接入”。

## 有道适配与密钥

先访问官方语音合成文档，确认**当前**接口地址、签名算法、日语音色 ID、语言字段、字符限制、音频响应和错误编码，不要凭印象猜参数。确认生成音频的缓存和网站播放许可，并记录所用官方文档链接。

环境变量建议为 `YOUDAO_APP_KEY`（应用 ID）、`YOUDAO_APP_SECRET`（应用密钥）；需要时用 `YOUDAO_JA_VOICE` 配置已验证的日语音色。实际命名若不同需同步文档。密钥只放本机未跟踪的环境文件或部署平台 Secret，不要求用户在聊天中粘贴。禁止使用 `NEXT_PUBLIC_`、前端签名、日志打印密钥或将真实密钥写入 Git。

仅已登录账号能看到喇叭和调用 API；游客不显示按钮，实际到达服务端的请求必须校验有效会话。已下载到浏览器的公开词库音频可离线保留，退出登录会隐藏按钮并停止播放，但不清除音频。复用同源请求校验；防止接口成为消耗额度的无限合成代理。保留适合多实例部署的账号限流，但**不要实现数据库音频缓存**，旧音频表不再读写，也不要删除已部署迁移。不要把音频写到 Netlify 函数临时磁盘。取消请求、设置有限超时；检查供应商的 JSON 错误/Content-Type/实际音频，不能把错误当成音频返回。不要把供应商含密钥的原始请求或响应暴露给浏览器。

前端默认 `requestSpeech` 已指向此接口，另外保留了可注入 `SpeechTransport`，无需增加前端 SDK。所有喇叭共享 48 条 / 24 MiB 内存热缓存、无主动过期的 Cache Storage 和一年期 HTTP 私有缓存；合并页内并发请求，并在支持 Web Locks 时跨标签页去重。取消播放不丢弃已付费合成结果，成功后继续缓存；仅合成请求有 20 秒上限。浏览器清理 / 回收存储或换设备仍可能重新请求，不能保证永不调用。修改文本 / 音色需提升缓存版本。持久缓存应遵守供应商许可。

## 验证

只做必要的轻量验证：确认签名符合官方文档、读音/例句文本解析正确，以及参数错误、未配置、供应商错误和超时能返回明确提示。需要自动化时只补最小范围的服务端单元测试，模拟供应商，不消耗真实额度。

不要新增或运行 E2E、Playwright、截图巡检，也不要反复调整前端。在用户已通过环境变量配置密钥后，手动播放一个单词读音和一个例句，确认真实接通；未配置时明确说明未做真实联调，不要把模拟通过当成真实通过。

执行 `npm run lint` 和 `npm run build`；如新增服务端单元测试，仅运行相关测试，无需全量测试。不要使用端口 3000，开发端口为 3107。

补充 `.env.example` 的占位配置及简短启用说明。最终说明需要用户配置什么、免费额度/超额计费风险、已验证的官方协议和真实联调结果，不要虚报完成。
